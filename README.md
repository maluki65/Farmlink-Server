# Farmlink Server

Farmlink Server is a backend application built with Flask and PostgreSQL to support the functionalities of the Farmlink platform. This guide will walk you through the setup process step-by-step, making it beginner-friendly.

---

## Features
- **Flask Framework**: A lightweight and flexible web framework for Python.
- **PostgreSQL Database**: A powerful, open-source relational database.
- **Environment Variables**: Securely manage sensitive data like database URLs and secret keys.

---

## Prerequisites
Before you begin, ensure you have the following installed on your system:
1. Python (version 3.8 or higher)
2. PostgreSQL (version 12 or higher)
3. Git (for cloning the repository)
4. A terminal or command-line interface
